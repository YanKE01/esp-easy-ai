# 时序数据集计划

## 1. 输入形式

时序任务的数据集先统一采用 `CSV` 上传。

补充：

- 当前前端已经先实现 `Data Classification` 的数据集入口
- `Data Classification` 当前采用数据集文件夹上传，不是单个 CSV 上传
- 参考结构：
  - 根目录下包含 `train/`
  - 根目录下包含 `test/`
  - 例如 `train_on.csv`、`test_on.csv`

## 2. CSV 结构

当前建议采用宽表格式。

示例：

```csv
timestamp,acc_x,acc_y,acc_z,label,series_id
0.00,0.12,0.01,0.98,a,a_1
0.02,0.14,0.03,1.01,a,a_1
0.04,0.13,0.02,0.99,a,a_1
```

字段约定：

- 必选：时间列
- 必选：至少一个信号列
- 可选：标签列 `label`
- 可选：序列列 `series_id`

## 3. 动作识别定义

对于加速度计 `x/y/z` 动作识别：

- 一行表示一个采样时刻
- 一次完整采集对应一个 `series_id`
- 同一次采集中的所有行使用同一个 `label`

可以直接这样理解：

- `label` 表示动作类别
- `series_id` 表示这是这个动作的第几次独立采集

例如：

- 动作 `a` 采集 5 次，对应 `a_1` 到 `a_5`
- 动作 `b` 采集 5 次，对应 `b_1` 到 `b_5`

## 4. 数据组织模式

当前 `Time Series` 只支持 `Sequence Sample` 模式。

这时的含义是：

- 一个 `series_id` 对应一段连续序列
- 一个序列对应一个样本
- 同一序列中的所有行共享同一个 `label`

对于加速度计动作识别，当前默认采用这种方式。

原因是：

- 单行 `x/y/z` 通常不足以表达一个完整动作
- 动作识别更依赖一段连续时间内的变化
- 训练输入和端侧推理输入都应对应一整段序列

像波士顿房价这种“一行 10 列就是一个样本”的数据属于表格数据，不属于当前 `Time Series` 范围，后续应单独归入 `Tabular` 类型。

## 4A. Data Classification 当前补充约定

当前已经明确，`1D` 下面需要同时支持：

- `Time Series`
- `Data Classification`

其中 `Data Classification` 当前先按下面方式处理：

1. 一个文件夹就是一个数据集
2. 数据集根目录下必须包含：
   - `train/`
   - `test/`
3. 每个类别通常对应一个文件
4. 当前类别名可先从文件名中解析，例如：
   - `train_on.csv -> on`
   - `test_clog.csv -> clog`
5. 每一行表示一个样本
6. 但一行内部可以按多通道交错组织，例如：
   - `x1 y1 z1 x2 y2 z2 ...`
7. `Number of Channels` 不自动推导，由用户手动输入
8. 上传文件夹后，前端弹出对话框要求用户填写 `Number of Channels`
9. 波形预览当前只需要显示某个类别中的一行数据
10. 波形图放前端实现，方便做 hover、缩放和快速校验

## 5. 列映射

上传 CSV 后，用户需要在页面中选择：

- `timestamp`
- signal 列，可多选
- `label`
- `series_id`

## 6. Dataset 页面结构

`Time Series -> Dataset` 页面包含：

1. `Upload CSV`
2. `Column Mapping`
3. `Preview`
4. `Dataset Split`
5. `Dataset Summary`

## 7. Dataset 页面流程

1. 上传 CSV
2. 展示列名
3. 选择时间列
4. 选择信号列
5. 选择标签列和 `series_id`
6. 填写样本输入规格
7. 设置训练集和测试集比例
8. 预览数据
9. 展示摘要信息

## 8. 数据集划分

当前只支持：

- `train ratio`
- `test ratio`

前端校验比例总和为 `100%`。

如果存在 `series_id`，划分按 `series_id` 进行，避免同一段序列同时进入训练集和测试集。

## 9. Dataset 页面展示

当前建议显示：

1. 原始数据表格预览
2. 基本摘要信息
3. 标签分布
4. 序列信息
5. 划分结果

## 10. 原始数据预览

原始数据表格采用分页查看。

当前固定：

- 每页 `20` 行

表格中需要能看见：

- 列名
- 分页数据
- 当前选择的时间列
- 当前选择的信号列
- 当前选择的标签列
- 当前选择的 `series_id` 列

## 11. Dataset 阶段定义输入规格

当前不支持流式识别。

输入规格在 `Dataset` 阶段定义，由用户直接填写：

- 采样间隔或采样频率
- 单个样本时长
- 单个样本点数
- 输入通道数
- 标签对应关系

例如：

- 采样周期：`1ms`
- 样本时长：`1s`
- 单样本点数：`1000`
- 输入通道：`acc_x, acc_y, acc_z`

则单个样本输入形状为：

- `1000 x 3`

## 12. Dataset 与 Training 边界

`Dataset` 阶段负责：

- 数据列映射
- 数据划分
- 样本长度
- 输入规格

`Training` 阶段直接继承这些定义，不重新定义输入长度。
